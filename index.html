TotoAuth

A small TOTP generator that runs entirely in your browser. Nothing leaves the page.

Accounts

    How it works

    A TOTP code comes from two inputs: a shared secret and the current time. Your device and the server both hold the secret and run the same calculation, so they land on the same six digits without ever exchanging anything over the wire.

    1. Unix time is divided by 30, producing a counter that ticks once every half minute.
    2. That counter is signed with the secret using HMAC-SHA1.
    3. The last byte of the signature picks an offset. Four bytes from that offset are read and reduced to six digits.
