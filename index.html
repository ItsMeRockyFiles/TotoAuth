How a code is made

30 SEC CYCLE
01

Turn time into a counter

floor(unix time / 30) gives this time window a number both sides can agree on.

02

Sign the counter

HMAC-SHA1 combines that counter with the shared secret enrolled with the service.

03

Truncate and format

Dynamic truncation selects 31 bits, then modulo 1,000,000 produces a six-digit code.
